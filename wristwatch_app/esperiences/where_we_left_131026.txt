2. VOLUME LATENCY ISSUE (RESOLVED & VERIFIED)
--------------------------------------------------------------------------------
Status: SOLVED (October 13, 2026 - 22:55)
Resolution Details: See `esperiences/volume_sync.txt` for the full technical post-mortem.

Root Cause:
- ESP32-C6 USB CDC Serial blocking timeout (`HWCDC.cpp`). Calling `Serial.printf`
  inside `VolumeLevelCallbacks::onWrite` blocked the single-core FreeRTOS NimBLE
  task for 1000ms per packet whenever the USB CDC buffer could not flush immediately.
- Flutter's write loop stalled on Android's GATT buffer waiting for ACK from the frozen ESP32.

Fix Applied:
1. `c6_media_display.ino`:
   - Removed `Serial.printf` from `VolumeLevelCallbacks::onWrite` (< 1 µs execution).
   - Added `Serial.setTxTimeoutMs(0)` in `setup()` for non-blocking USB CDC output.
   - Removed conflicting `pServer->updateConnParams` from `ServerCallbacks::onConnect`.
   - Declared `volatile int currentVolume = 50;`.
2. Result:
   - Volume sync is now instantaneous (< 15ms) when dragging the in-app slider
     or clicking the phone's physical volume buttons.
